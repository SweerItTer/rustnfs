CARGO DEPENDENCIES

The complete name/version/license inventory is provided in:

  licenses/README.md
  licenses/dependency-inventory.csv
  licenses/dependency-inventory.json

It contains 61 distinct third-party name/version pairs across the locked
Windows x86-64 GNU and Linux x86-64 GNU non-dev dependency graphs. Each graph
contains 55 packages. Normal and build dependencies are included, including
procedural macros; dev-only dependencies are excluded. Inclusion in a build
graph does not assert that a package contributes machine code to every binary.

The declared license expressions come from the local Cargo package manifests
through cargo metadata --locked --offline. Verbatim Cargo.toml.evidence files,
original license/copyright/notice files, registry package checksums, and
SHA-256 hashes are included. No dependency license was inferred from its name.

Where a package explicitly offers MIT as an alternative, this distribution
uses that alternative together with any mandatory AND terms and separately
applicable file/data notices. All supplied original license alternatives are
nevertheless retained. In particular:

  - unicode-ident: (MIT OR Apache-2.0) AND Unicode-3.0; the Unicode term is
    mandatory, and the original LICENSE-UNICODE is included.
  - regex-syntax: its nested src/unicode_tables/LICENSE-UNICODE data notice is
    included in addition to the package-level MIT OR Apache-2.0 declaration.
  - tracing-core: its nested src/spin/LICENSE is included.
  - winx: Apache-2.0 WITH LLVM-exception; no MIT alternative is asserted.
  - nfs3_server: BSD-3-Clause; its copyright, conditions, and disclaimer remain
    applicable to the upstream source and derivatives.

STANDARD LIBRARY AND GNU WINDOWS RUNTIME

Cargo metadata does not inventory the Rust standard library or the external
Windows GNU runtime. Relevant notices shipped locally with the build tools
are supplied separately:

  licenses/runtime/rust-1.99.1/COPYRIGHT
  licenses/runtime/rust-1.99.1/LICENSE-MIT
  licenses/runtime/rust-1.99.1/LICENSE-APACHE
  licenses/runtime/rust-1.99.1/COPYRIGHT-library.html
  licenses/runtime/rust-1.99.1/licenses/
  licenses/runtime/mingw/

The Rust Standard Library generally offers MIT or Apache-2.0, with the
additional per-component notices recorded in its original COPYRIGHT-library
document. That complete document, rather than a simplified blanket license
claim, is retained here.

The MinGW-w64 and GCC package copyright documents contain per-file terms,
public-domain notices, and applicable runtime exceptions. They also describe
components of the toolchain beyond this application. Their presence does not
mean the GCC compiler is redistributed with RustNFS or that RustNFS-authored
code is licensed under the compiler's GPL terms. Source package versions and
original notice-file hashes are in dependency-inventory.json.
